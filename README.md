Авторская браузерная игровая консоль: Next.js App Router, React, строгий TypeScript, Tailwind CSS, Motion, Zustand, Three.js, Auth.js, PostgreSQL и Prisma. Мультиплеер — отдельный Colyseus-сервер с общей авторизацией и серверной симуляцией. Русский язык по умолчанию, английский — в настройках. Игровой код и визуальная композиция созданы для проекта; лицензированные модели Car Concept и Bistro указаны в [реестре ассетов](public/game-assets/manifest.json).

## Локальная разработка

Нужны Node.js **24 LTS** (не ниже 24.0), npm и Docker с Compose.

```bash
npm ci
node scripts/init-env.mjs
docker compose up -d --wait db
npm run db:generate
npm run db:migrate
npm run db:seed
docker compose up -d --build --wait game-server
npm run dev
```

Приложение слушает порт 3000. `init-env.mjs` создаёт `.env` со случайными локальными паролями и ключом сессий, сохраняет существующий файл и ничего секретного не печатает. В `.env.example` перечислены настройки. Существующая база не очищается. Seed идемпотентен: не перезаписывает изменения администратора и не добавляет игры пользователям.

Игровой процесс слушает 2567. Для разработки без контейнера вместо `game-server` запустите `npm run game:dev` в отдельном терминале. В этой облачной среде используйте `sh scripts/cloud-compose.sh up -d --build --wait game-server`: wrapper корректно передаёт proxy/DNS и доверенный CA только в сборку, без отключения TLS. Не запускайте две копии игрового сервера против одной базы. Миграции и сборку с генерацией Prisma выполняйте до запуска процессов.

Для собственной PostgreSQL укажите `DATABASE_URL` и пропустите Docker. Данные Compose лежат в именованном volume. Не удаляйте volume, если хотите сохранить аккаунты и прогресс.

```bash
npm run build
npm start
```

Сборка использует webpack. Приложение не зависит от платных API, CDN, внешних шрифтов или сторонних изображений. Prisma 7 использует PostgreSQL driver adapter; URL миграций находится в `prisma.config.ts`.

## Визуальная версия After Hours

Новый главный экран использует полноэкранный игровой фон, горизонтальную личную коллекцию и прямой запуск. Гонка загружает локальные GLB Car Concept и Bistro, PBR-асфальт и HDR-окружение; колёса и стоп-сигналы анимированы. В паузе доступны Auto, Low, Medium и High, а также авторы ассетов. Auto выбирает облегчённый режим на программном WebGL и уменьшает разрешение при медленных кадрах. Выбор качества относится к устройству.

[Художественное направление и лицензии](docs/visual-overhaul/art-direction.md), [реальные снимки и замеры](docs/visual-overhaul/README.md). Key art гонки снят из её настоящего рендера; будущие игры используют концептуальные изображения и остаются недоступными для запуска. Изменения стандартной графики применяются при чтении каталога: собственные изображения администратора и данные базы не перезаписываются.

Все подготовленные ассеты находятся в `public/game-assets`; для установки, сборки и запуска **не нужен** их повторный импорт. Необязательная пересборка художественных файлов:

```bash
python3 -m venv .asset-tools
.asset-tools/bin/pip install Pillow==12.3.0
PATH="$PWD/.asset-tools/bin:$PATH" npm run assets:prepare
```

Команда требует интернет, проверяет ранее принятые хеши источников, восстанавливает материалы Bistro и создаёт GLB с Meshopt и WebP. Кэш `.asset-cache` и Python-окружение не входят в исходники. При изменении исходного хеша необходимо заново проверить содержание и лицензию, прежде чем обновлять manifest. GLB и текстуры загружаются с собственного origin, декодер включён в bundle; загрузка не подменяется техническими моделями при ошибке.

## Первый аккаунт и администратор

1. Зарегистрируйтесь через интерфейс. Библиотека нового аккаунта пуста.
2. Откройте каталог, выберите MIDNIGHT OUTLAWS, добавьте игру.
3. Запустите её из библиотеки или с главного экрана.
4. Чтобы повысить **существующий** аккаунт до ADMIN, в доверенной серверной консоли выполните:

```bash
npm run admin:create -- player@example.com
```

Публичной регистрации администраторов, стандартного административного пароля и демонстрационного авторизованного пользователя нет. `/admin` проверяет роль на сервере; все административные API проверяют её независимо от страницы. Новая карточка с зарегистрированным runtime может быть опубликована как доступная. Без сборки допускается только черновик или «Скоро». При наличии истории или сохранений физическое удаление запрещено: снимите карточку с публикации.

Обложки и баннеры можно выбирать из `/art/` либо загружать из админки: PNG/JPEG/WebP до 5 МБ и 20 мегапикселей. Sharp декодирует и перекодирует изображение в WebP, удаляя метаданные; SVG-загрузки запрещены. Файлы хранятся в `storage/uploads` и выдаются через строго ограниченный media route. Для production сохраняйте этот каталог на постоянном диске.

## MIDNIGHT OUTLAWS

Шесть автомобилей с отдельными моделями и конфигурациями физики доступны в гараже. Сохранены городская дорожная сеть, Free Drive и три городских маршрута; добавлены автодром Velocity Circuit, горный Eagle Ridge и прибрежный Coastline Run. Вместе с прежним кольцом доступны семь сетевых маршрутов. Рекорды разделены по ID и версии маршрута; старые сохранения сохранены.

Three.js-визуализация использует общую с сервером геометрию дорог и фиксированную аркадную симуляцию. Есть интерполированная камера, нитро, контакты с окружением, последовательные контрольные точки, мини-карта и настраиваемая динамическая траектория. Публичные сетевые гонки проходят без контактов между автомобилями. [Проверки обновления и ограничения](docs/racing-experience/README.md).

- Клавиатура: W/↑ — газ; S/↓ — тормоз; A,D/←,→ — руль; Shift — нитро; Space — ручной тормоз; C — камера; Esc — пауза; R — заново.
- Стандартный геймпад: левый стик — аналоговый руль; RT/R2 — аналоговый газ; LT/L2 — аналоговый тормоз; A/Cross — нитро; X/Square — ручной тормоз; B/Circle — камера; Menu/Options — пауза.
- Сенсорное управление: экранные кнопки руля, газа, тормоза и нитро на touch-устройствах.
- Интерфейс консоли: стрелки/Tab — фокус; Enter — выбор; Escape — назад; геймпад D-pad/стик, A — выбор, B — назад, Y — библиотека.

Одиночный режим включает свободную тренировку и заезды на время с личной таблицей десяти лучших кругов. Тренировка не отправляет соревновательные результаты. Онлайн-режим — 2–6 реальных участников, общие countdown/старт/контрольные точки/финиш, выбор машины, Ready, таблица результатов и повторная гонка. На телефоне сетевой режим честно отключён; одиночный поддерживает touch.

Сессия создаётся при нажатии «На старт». `Last Played` сохраняется в PostgreSQL. Активное время учитывается heartbeat-запросами, пауза и возврат на вкладку обрабатываются отдельно. Лучший завершённый круг сохраняется для текущего пользователя. Удаление игры из библиотеки сохраняет её историю и результаты.

## Управление контроллером

Единый `NexusInputManager` обслуживает консоль и игры. Пространственный фокус, D-pad/левый стик, LB/RB для разделов, контекстное меню игры, правый стик для прокрутки и экранная клавиатура позволяют зарегистрироваться, войти и работать с библиотекой без физической клавиатуры. После выхода из игры восстанавливается выбранная карточка. Подсказки учитывают последний метод ввода и выбранную раскладку.

В `/controllers` доступны устройства, проверка аналоговых кнопок и стиков, dead zone, чувствительность, инверсии, переназначение, интенсивность вибрации и до восьми профилей в аккаунте. Страница доступна и до входа для настройки нестандартного устройства. После отключения ввод обнуляется: одиночная игра открывает паузу, сетевая продолжает общую сессию с нейтральными командами. Подробности и честная матрица совместимости — [Controller Input](docs/controllers.md), результаты — [проверка контроллеров](docs/controller-validation.md).

Предусмотрены PlayStation, Xbox, Nintendo, standard и собственные раскладки. Физические USB/Bluetooth-устройства в этой среде отсутствуют: поддержка конкретной комбинации устройства, ОС и браузера пока не подтверждена. Программная вибрация зависит от браузера; адаптивные триггеры не обещаются.

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run test:e2e
npm run test:wss
npm run test:restart
```

Для функциональных E2E в CI без GPU можно явно задать `E2E_SOFTWARE_DPR=0.15 npm run test:e2e -- --trace=off`: логические размеры интерфейса сохраняются, уменьшается только разрешение WebGL/screenshot backing buffer. Непрерывная запись кадров трассировки вызывает дорогое чтение пикселей на SwiftShader; трассу можно отдельно включить при диагностике. Это проверка действий и данных, а не производительности или качества картинки. Визуальные снимки и замеры выполняются отдельно при DPR 1. Фиксированный клиентский цикл 30 Гц не зависит от частоты представления кадров; сырые опросы устройств не передаются по сети.

Playwright использует системный Chromium, если он установлен, либо свой браузер. При необходимости установите его: `npx playwright install --with-deps chromium`. Для другого бинарника задайте `CHROMIUM_PATH`.

Игровой сервер должен быть запущен отдельно. E2E запускает dev-сервер, если порт 3000 свободен. Для проверки production сначала выполните `npm run build && npm start`, затем запустите тесты. Тесты создают аккаунты с уникальными тестовыми префиксами и удаляют только свои данные. Для CI рекомендуется отдельная PostgreSQL; схема должна быть мигрирована и seed применён до тестов. Отчёт — `playwright-report/index.html`, трассы неуспешных сценариев — `test-results/`.

Сценарии: A — регистрация/пустая библиотека/добавление; B — повторный вход/избранное; C — реальный WebGL и управление машиной; D — изоляция аккаунтов и подмена идентификаторов; E — публикация администратором; F — мобильный интерфейс. Дополнительно проверяются сохранность прогресса, локализация, доступ и ограничение входа. Модульные тесты проверяют хеширование, схемы валидации, runtime registry, столкновения, нитро и полный круг в симуляции.

## Друзья и онлайн-гонки

Friends включает поиск username, запросы/принятие/отклонение/удаление, блокировки, присутствие, приватность, приглашения и историю матчей. Группа поддерживает приглашения, выход, передачу лидерства и общий поиск с резервированием мест. Быстрый матч находит настоящее публичное лобби или создаёт новое и ждёт участников.

Клиент отправляет только ввод. Сервер симулирует физику на 30 Гц, рассылает снимки на 15 Гц и сохраняет результаты транзакционно. Локальное предсказание, reconciliation, интерполяция удалённых машин, ограниченная экстраполяция, индикатор сети и переподключение на 30 секунд реализованы в общей сетевой архитектуре. Приватные одиночные рекорды не считаются серверно проверенными сетевыми результатами.

[Полная документация multiplayer](docs/multiplayer.md) описывает токены, SDK, адаптеры игр, метрики ADMIN, WSS и локальный/production запуск. [Измеренные сетевые прогоны](docs/multiplayer-test-results.json) включают задержку, jitter, потери команд и шесть одновременных комнат. `test:wss` использует настоящее TLS-соединение с явно доверенным тестовым CA; проверка сертификатов включена. `test:restart` создаёт и удаляет отдельную временную базу, поэтому нужен PostgreSQL-пользователь с CREATEDB; основной процесс не перезапускается.

## Авторизация и безопасность

Пароли хешируются scrypt с индивидуальной случайной солью (N=32768, r=8, p=1). Сравнение выполняется за постоянное время. Credentials provider Auth.js использует зашифрованный HTTP-only JWT cookie. Обычная сессия действительна сутки, «Запомнить» — 30 дней; сервер проверяет внутренний срок и `tokenVersion` из базы. Сброс пароля отзывает прежние сессии. Таблицы Account, Session, VerificationToken подготовлены для расширения Auth.js; при credentials-сценарии применяется JWT, а не database session strategy.

Ограничения частоты хранятся в PostgreSQL и работают между процессами: на email и на общий поток входов. Регистрация и восстановление тоже ограничены. `TRUST_PROXY=false` по умолчанию: произвольный `X-Forwarded-For` не даёт обойти лимит. Включайте его только за доверенным proxy, который заменяет forwarded-заголовки. Все изменяющие собственные API проверяют Origin и серверную сессию, Auth.js применяет свою CSRF-защиту. Идентификатор пользователя берётся только из сессии. Секреты не передаются клиенту.

Для восстановления пароля задайте реальные `SMTP_URL` и `MAIL_FROM` в защищённой серверной конфигурации и перезапустите приложение. Без SMTP форма честно отключена и API возвращает 503. Одноразовый 256-битный токен живёт 30 минут; в базе хранится только SHA-256-хеш; потребление и изменение пароля транзакционны. Отправка писем не тестируется без настоящего SMTP.

Для развёртывания задайте HTTPS `NEXTAUTH_URL`, сохраните уникальный `NEXTAUTH_SECRET`, используйте TLS до базы и делайте резервные копии PostgreSQL и uploaded assets. Secure cookie автоматически включаются Auth.js на HTTPS. TLS, проверка целостности пакетов и проверка сертификатов не отключаются.

## Подключение следующей игры

См. [Game Runtime](docs/game-runtime.md). Полный manifest и явный registry разделяют метаданные каталога и проверенный исполняемый модуль. Админка не принимает серверные пути, команды или исполняемые архивы.

## Границы первой версии

- **Одна** работающая игра. ORBITAL SILENCE, EVERGREEN и ECHOES OF LIGHT — честно обозначенные будущие концепции без игровых сборок, отзывов, рейтингов или фиктивной статистики.
- Внутренний Three.js runtime работает. Типы интерфейсов предусматривают Canvas/WebGL/WASM/WebGPU/external sandbox. Для Underground зарегистрирован экспериментальный WASM launcher с отдельным origin и собственным локальным комплектом пользователя; оригинальный игровой процесс здесь не проверен. Остальные незавершённые адаптеры не зарегистрированы.
- Публичные профили, OAuth и платежи не подключены; неработающих кнопок этих функций нет. Настройка приватности сохраняется для будущих публичных профилей; сейчас все профили доступны только владельцу.
- Это аркадная дорожная физика с шестью конфигурациями машин, городом и тремя отдельными трассами. Полная динамика подвески, прыжки и перевороты не реализованы. Публичная сетевая гонка работает без контактных столкновений машин. Частота кадров зависит от GPU. Автотесты используют software WebGL; физический геймпад и реальные мобильные GPU требуют отдельной аппаратной проверки.
- Одиночные рекорды проходят базовую проверку времени сессии; сама одиночная симуляция работает в браузере. Эти рекорды приватны и не используются для рейтинга. Сетевую гонку симулирует сервер, который определяет и сохраняет её результат.
- Игровой звук использует Web Audio: двигатель по оборотам и нагрузке, передачи, шины, удары, окружение и отдельные настройки громкости в аккаунте. Звук активируется после действия пользователя; при блокировке браузером показана кнопка включения. Это оригинальный синтез, не профессиональные записи двигателей. Настройка UI-звуков консоли независима.
- Исходная публичная установка размещена на Render; сейчас владелец видит страницу suspension. Подготовка Northflank описана отдельно. Docker Compose с Caddy остаётся альтернативой для собственного сервера. Filesystem uploads требуют постоянного диска, database media mode — места в PostgreSQL. Обновление/перезапуск временно прерывает доступ, активные комнаты не переносятся между процессами.

Фактические результаты проверок и ограничения среды записаны в [docs/validation.md](docs/validation.md).

SMTP-восстановление использует `emailjs` и только `smtps://` с обязательной проверкой сертификата (обычно порт 465); отправка паролей через незашифрованный SMTP не допускается. CSP создаётся с уникальным nonce для каждого серверного ответа; production не разрешает inline-скрипты без nonce или `eval`. Inline-стили разрешены для Motion и динамического игрового HUD.
