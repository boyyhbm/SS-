# MIDNIGHT OUTLAWS — City Streets update

Доработка существующей игры. Авторизация, библиотека, роли, друзья, Party, Colyseus и прежние пользовательские записи сохранены. Миграций БД для обновления нет.

## Что изменено

- Chase Camera: дистанция 7,8 м, Close Chase 5,8 м, Hood и прежний режим осмотра. Сглаживается угол сопровождения; линейного отставания от разгоняющейся машины нет. FOV по умолчанию 58°, опциональное изменение ограничено 0,8°. Настройки разработчика — `src/games/visual/camera.ts`.
- Дорожный граф: 17 узлов, 26 связей, центр, промышленные кварталы и набережная. Асфальт объединяется в одну поверхность с вырезами под кварталы; тротуар — разность расширенной сети и асфальта. Поверхности перекрёстков не наложены друг на друга.
- Разметка: метрическая длина центральной линии, касательная и поперечная нормаль общие с дорогой. Постоянная ширина линий, равномерный пунктир, разрывы у узлов, переходы и стоп-линии на подходах к T/X/Y-соединениям.
- Три маршрута: **Кольцо центра** (0,7 км, 3 круга), **Полуночный спринт** (1,0 км, разные старт и финиш), **Промышленный заезд** (1,1 км, 3 круга). Маршруты заданы отдельно от геометрии; ворота проверяют порядок, направление и действительное пересечение. Free Drive позволяет выбирать ветви всей сети и разворачиваться.
- Аркадное вождение: сглаженные газ/тормоз/руль, зависимость чувствительности от скорости, инерция сцепления, ручной тормоз, нитро и задний ход после остановки. Фиксированный шаг 30 Гц. Капсула кузова согласована с размерами машины; непрерывная проверка движения до бордюра и реальные препятствия припаркованных машин предотвращают радиальные телепортации.
- Рекорды новых маршрутов хранятся раздельно в `best-lap:<routeId>` / `lap-history:<routeId>`. Старые `best-lap` / `lap-history` не перезаписываются; прежняя история доступна в архиве меню.
- PBR-асфальт: новые albedo/roughness, общая мелкая normal map, слабая непрерывная вариация влажности. Удалён дополнительный резкий planar mirror с пятнистой маской. Отражения используют фильтрованное HDR-окружение и физический материал с умеренной шероховатостью.
- Машина сохраняет лицензированную GLB-геометрию, получила настроенные лак/стекло/фонари, контактную тень, опору по реальной нижней границе модели и вращение колёс по их геометрическому радиусу.
- Город: дополнительные лицензированные фасады и деревья, LOD, пространственная группировка, инстансы, остановки, урны, парковка, автомобили, ограждение набережной, крышки и дренаж. Исправлено сопоставление имён glTF/Godot: `.001` → `_001`; растительность получает настоящие текстуры и alpha mask. Новые источники и SHA-256 находятся в [реестре](../../public/game-assets/manifest.json), лицензия — CC BY 4.0.

## Настоящие проверки и материалы

**[Видео реального игрового процесса — MP4, 3:50, 5 МБ](gameplay.mp4)**: разгон с проверкой камеры, затем участки всех трёх маршрутов с поворотами. Запись из браузера, без подмены позиций и синтеза кадров. Контейнер 1280×720 / 25 кадров в секунду содержит повторы реально медленно отрисованных кадров; 25 FPS кодирования **не означает** 25 FPS игры. Видео не подтверждает плавность на физическом GPU. [Протокол записи](video-report.json).

Production build, TypeScript, ESLint, **88 unit-тестов и 19 браузерных сценариев** прошли на исходном commit `2cde787`: [GitHub Actions](https://github.com/boyyhbm/SS-/actions/runs/40214485818). Дополнительно три новых городских сценария отдельно прошли на локальной production-сборке за 3,8 минуты: порядок ворот, настоящий финиш/круг, запись рекорда своего маршрута. [Сводка проверки](validation.json).

- [Маршруты в браузере](routes-report.json): все три действительно пройдены до завершения круга/спринта. Для кольцевых маршрутов это первый полный круг из трёх; это не заявление о трёх полных кругах в этом прогоне. Проверены виртуальный аналоговый Gamepad API и клавиатура. Позиции/контрольные точки/результаты не подменяются.
- [Проверка камеры](camera-report.json): скриншоты и видео действительного разгона 0/50/100/около 150 км/ч. Измеряется проекция границ загруженной GLB, **не** сегментация пиксельного силуэта. FOV 58°, дистанция 7,8 м; математические тесты отдельно проверяют обычное сглаживание, дополнительный FOV и 30/60/120 FPS.
- [Галерея реального рендера](gallery.md), [протокол снимков](screens-report.json): [прямая](straight-markings.png), [поворот](curved-markings.png), [перекрёсток](junction.png), [машина](car-close.png), [окружение](industrial-environment.png), [карта маршрутов](route-map.png).

`scripts/qa-city.ts` воспроизводит проверки только на локальном адресе с отдельной QA-базой. Автодрайвер использует неизменяемый диагностический снимок перед шагом физики и подаёт команды через Gamepad API/KeyboardEvent. Это позволяет проверить физику при медленном программном рендере, но не подтверждает совместимость физического контроллера. Опциональная диагностика не даёт менять состояние симуляции или серверные результаты.

```bash
node --experimental-strip-types scripts/qa-city.ts routes
node --experimental-strip-types scripts/qa-city.ts camera
node --experimental-strip-types scripts/qa-city.ts screens
node --experimental-strip-types scripts/qa-city.ts video
node --experimental-strip-types scripts/qa-city.ts performance
```

Для записи используется FFmpeg. В текущей среде CDN Playwright был недоступен; применён системный FFmpeg 7.1.5 через его ожидаемый путь в кэше Playwright. Видео записывается из настоящего окна игры, без синтеза кадров или ускорения воспроизведения.

## Границы готовности

**Новые городские маршруты пока одиночные.** Действующая сетевая гонка продолжает использовать прежнее кольцо с прежней серверной физикой. В интерфейсе это обозначено; ни одной новой сетевой трассы без проверки синхронизации не объявлено. Чистые TS-модули графа, маршрутов и физики готовы для будущего адаптера с отдельным проверенным режимом.

Это компактный прототип с лицензированной архитектурой, а не AAA-город. Части фасадов остаются глухими, транспортный трафик и пешеходы не реализованы. Контактных столкновений между сетевыми участниками по-прежнему нет. Профили High/Medium/Low сохранены; Auto адаптирует разрешение и выбирает Low для software WebGL.

Физического игрового ПК и контроллеров в контейнере нет. Цель 60 FPS High/1080p **не подтверждена**. На доступном программном SwiftShader получено Low 0,72 / Medium 0,32 / High 0,31 / Auto 1,10 FPS: это медленный программный рендеринг, не достигнутая игровая производительность. [Фактическая конфигурация, время кадра, память и ресурсы](performance.md), [сырые измерения](performance-report.json). Аппаратная проверка производительности и совместимости USB/Bluetooth остаётся обязательной перед объявлением полной готовности.
