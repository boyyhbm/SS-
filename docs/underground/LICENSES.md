The preparer fetches only the pinned open tool repository and pinned Python packages, and reads the user's game from disk. Its output contains protected content and is explicitly private. The public resource manifest forbids `.wasm`, `.exe`, game directories and arbitrary asset serving. No cloud save or game-file upload endpoint is introduced.

Before any public **Stage B** artifact distribution: establish the necessary rights for the original code/assets, inventory the exact compiler/static-runtime contents and licenses for that artifact, retain all required notices, and review distribution terms. This integration has no mechanism that automatically promotes Stage A files to Stage B.

Local audit also downloaded the exact pefile/Capstone wheels and inspected their included MIT / BSD-3-Clause notices. The wasi-sdk source LICENSE at `2b65040ed01044c978468e545473cb3c1b69e097` was inspected separately; the exact owner-selected SDK binary and linked-runtime inventory remain build-specific.
