# Фактические замеры производительности

**Требование High / 1080p / 60 FPS не подтверждено.** В облачной среде нет игровой видеокарты: используется программный ANGLE/SwiftShader. На этой конфигурации игра работает медленно; результаты ниже не означают прохождение приёмки плавности на игровом ПК.

Измерено 25 октября 2026 года на Intel Xeon Platinum 8573C, Linux 6.18.55, Node 24.19, Chromium 154. CPU-квота контейнера — 4 ядра, navigator.hardwareConcurrency — 5, память контейнера — 32 GiB. Отдельные браузерные тесты, сборки и кодирование видео во время замеров не запускались.

Сцена: реальная Downtown Circuit, движение через нормализованный виртуальный аналоговый контроллер, целевая скорость 18 м/с, штатная физика и PBR/GLB. Viewport 1920×1080, DPR устройства 1; фактическое разрешение canvas зависит от пресета. После первых трёх отчётов загрузки собирается 100 активных межкадровых интервалов на каждый пресет. Пауза исключена. Это короткая выборка, а не длительный нагрузочный тест.

Средний FPS — 1000 / средний интервал; 1% low — 1000 / среднее самых медленных ceil(N × 0,01) интервалов. При N=100 это один самый медленный кадр, оценка чувствительна к выбросам. Все 100 интервалов каждого пресета превышают 50 мс на SwiftShader. Render submit измеряет только CPU-время отправки команд, не GPU-время и не полный кадр. GPU memory недоступна через используемый WebGL API; размеры JS heap указаны в JSON и не являются памятью GPU.

Low рендерит 1632×918, Auto в этой программной конфигурации выбирает 1152×648. Это явно указанное внутреннее разрешение, а не подтверждение нативных 1080p. High и Medium проверены с canvas 1920×1080.

Исправление устаревших поз подтверждено отдельной диагностической записью: 0 кадров с alpha вне диапазона после исправления. Детерминированные проверки физики/интерполяции при 30/60/120 Гц не заменяют аппаратные измерения дисплея. Нужны дополнительный прогон High/1080p на физическом игровом ПК, 30/60/120 Hz, visual QA сетевых коррекций и измерение 1% low по длительной записи. Физические контроллеры, Safari/Firefox и географически разнесённые клиенты здесь не проверялись.
